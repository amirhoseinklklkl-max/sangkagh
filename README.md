# 🗡 سنگ کاغذ قیچی — نبرد پهلوانان ایران‌زمین

بازی موبایل «سنگ کاغذ قیچی» با تم باستانی ایرانی، ساخته‌شده برای **اندروید استودیو** (Kotlin + Java).

## 📱 مشخصات

| مورد | مقدار |
|---|---|
| زبان | Kotlin + یک کلاس Java (`PersianUtil`) |
| minSdk / targetSdk | 24 (اندروید ۷) / 34 |
| فونت | لاله‌زار (در `res/font/lalezar.ttf`) |
| رویداد | RTL کامل و فارسی |
| کامپایل | AGP 8.2.2 + Gradle 8.2.1 + JDK 17 |

## ▶️ اجرا در اندروید استودیو

1. **File → Open** و پوشه `SangKaghazGheychi` را باز کنید.
2. صبر کنید Gradle Sync تمام شود (اولین بار چند دقیقه طول می‌کشد).
3. دکمه **Run ▶** را بزنید یا از منوی **Build → Build APK(s)** خروجی بگیرید.
4. فایل APK در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

> اگر Gradle Sync خطا داد: در **Settings → Build Tools → Gradle** گزینه Gradle wrapper را انتخاب کنید و مطمئن شوید JDK 17 تنظیم است.

## 🎮 بخش‌های بازی

### منو
- شروع بازی / فروشگاه / خروج
- باکس سکه و آمار پیروزی و باخت (با انیمیشن معلق)

### نبرد
- ۵ راند؛ لوزی هر راند: **طلایی = برد، قرمز = باخت، آبی = مساوی**
- انتخاب دست پایین صفحه → دست‌های بزرگ به سمت مرکز حرکت می‌کنند، دست حریف (هوش مصنوعی) بعد از چرخش بین حالت‌ها، دستش را نشان می‌دهد.
- حریف‌ها با نام‌های قدیمی: سردار گودرز، پهلوان پنبه، آرش کمانگیر، رستم دستان، سهراب، کاوه آهنگر
- **حساب‌وکتاب مخفیانه:** هر برد راند +۱۵ سکه، هر باخت -۵ سکه، مساوی ۰ — تا پایان نبرد نمایش داده نمی‌شود و فقط نتیجه نهایی دیده می‌شود.

### فروشگاه (۳ بخش)
- **دست‌ها:** ۸ پوست — پهلوانی، تتو گل، پرچم ایران، سرباز هخامنشی، مفرغی، طلایی، خاتم‌کاری، شاهنشاهی. انتخاب کارت با طلایی شدن باکس، پیش‌نمایش بزرگ با چرخش بین سنگ/کاغذ/قیچی، متن «در گنجور توست/نیست» و دکمه «بر تن داری / بهر و بپوش».
- **پس‌زمینه‌ها:** تخت جمشید (پیش‌فرض)، برج آزادی، کویر و کاروان، پارسه در شب — بعد از خرید در **همه صفحات** اعمال می‌شود.
- **بازار سیاه:** بسته شاهنشاهی (فقط مایکت) + ۳ بسته سکه (فعلاً فقط UI؛ دیالوگ «به‌زودی»).
  - 🔒 **حالت تست:** نگه‌داشتن انگشت روی کارت بسته شاهنشاهی، آن را رایگان باز می‌کند.
- دکمه **کلاکت جایزه** (پایین-چپ) فعلاً پیام «به‌زودی» نشان می‌دهد؛ بعداً جای تبلیغات را می‌گیرد.

### اقتصاد
| رویداد | سکه |
|---|---|
| شروع بازی | ۱۰۰ |
| برد هر راند | +۱۵ |
| باخت هر راند | -۵ |
| مساوی | ۰ |
| پوست‌ها | ۱۲۰ تا ۴۵۰ |
| پس‌زمینه‌ها | ۲۰۰ تا ۴۰۰ |

## 🔧 سفارشی‌سازی

### جایگزینی گرافیک با طرح‌های خودتان
همه تصاویر در `app/src/main/res/drawable/` هستند. کافی است هم‌نام آن‌ها را جایگزین کنید:

| الگوی نام | توضیح |
|---|---|
| `hand_<پوست>_<حالت>.png` | ۸ پوست × fist / scissors / palm (مثل `hand_gol_fist.png`) |
| `bg_<نام>.png` | پس‌زمینه‌ها + `bg_<نام>_thumb.png` برای کارت فروشگاه |
| `coin.png` | آیکون سکه |

نام پوست‌ها در `data/Skins.kt` و نام پس‌زمینه‌ها در `data/Backgrounds.kt` تعریف شده‌اند.

### تغییر قیمت‌ها و اسم‌ها
- قیمت‌ها: `Skins.kt` و `Backgrounds.kt`
- اسامی حریف‌ها: `data/Opponents.kt`
- قوانین سکه: ثابت‌های `WIN_COIN` و `LOSE_COIN` در `game/RpsGame.kt`
- متن‌ها: `res/values/strings.xml`

### اتصال مایکت (قدم بعدی)
جای اتصال SDK مایکت در دو تابع آماده است:
- `ShopFragment.imperialPack()` → دکمه «خرید از مایکت»
- `ShopFragment.coinPack()` → بسته‌های سکه

کافی است به‌جای `iapDialog()` فراخوانی billing مایکت را قرار دهید و در callback موفق، `GamePrefs.addOwnedSkin("imperial")` یا `GamePrefs.coins += مقدار` را صدا بزنید.

## 🗂 ساختار کد

```
app/src/main/java/com/ancientpersia/rps/
├── MainActivity.kt          → ناوبری بین سه صفحه
├── data/
│   ├── GamePrefs.kt         → ذخیره سکه، آمار، خریدها (SharedPreferences)
│   ├── Skins.kt             → تعریف ۸ پوست دست
│   ├── Backgrounds.kt       → تعریف ۴ پس‌زمینه
│   └── Opponents.kt         → اسامی و پوست تصادفی حریف
├── game/
│   ├── Gesture.kt           → سنگ/کاغذ/قیچی
│   └── RpsGame.kt           → موتور ۵ راند + محاسبه مخفی سکه
├── audio/SoundManager.kt    → افکت‌های صوتی (SoundPool)
├── util/
│   ├── PersianUtil.java     → ارقام فارسی (کلاس Java!)
│   └── Res.kt               → دسترسی به drawable با نام رشته‌ای
└── ui/
    ├── MenuFragment.kt      → منوی اصلی
    ├── GameFragment.kt      → صفحه نبرد و انیمیشن‌ها
    └── ShopFragment.kt      → فروشگاه سه‌بخشی
```
